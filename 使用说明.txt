舞蹈体操教学评分系统 · Windows 免安装版

运行要求：Windows 10/11，64 位 Intel/AMD 电脑。

双击 舞蹈体操教学评分系统.exe 即可运行，不需要安装 Python。
软件已包含人体识别模型、Python、界面库、FFmpeg 解码器及 VC++/UCRT 运行库。
软件还内置 left.mp4 和 right.mp4，首次启动即可使用默认视频评分。
视频分析无需联网下载模型或安装 Python/pip。
单文件启动会解压运行资源，请等待窗口出现。

使用方法：
1. 左侧选择标准动作视频，右侧选择待评分视频。
2. 顶部设置播放速度，点击“开始评分”。
3. 两段视频均结束后，弹窗显示分数；点击“确认”关闭弹窗。
4. 可点击“停止”取消本次评分。

视频请使用同视角、单人、全身清晰可见的片段。
内置的左右默认视频会随软件一起复制；额外自选视频需自行复制并重新选择。
高倍速播放受电脑识别性能限制；分数用于动作相似度参考。

默认视频路径和倍速保存在：
%LOCALAPPDATA%\ActionScorer\settings.json

本程序使用 MediaPipe、OpenCV、NumPy、Pillow、Python/Tkinter 和 PyInstaller。

便携目录版：解压全部文件，双击 舞蹈体操教学评分系统.exe，保留 _internal 目录。
目录版不必每次启动解压，适合离线电脑和临时目录受限的环境。
单文件版：单独复制 EXE 即可，启动需要等待资源解压。

兼容范围：目标为 Windows 10/11 x64，已在 Windows 10 x64 验证。
打包所有运行库仍无法替代旧系统缺少的 Windows API 或 CPU 指令集。
不承诺 Windows 7/8、32 位系统或 ARM 原生运行。
